# Healthcare data analysis
Excel-based hospital data analysis, pivot tables and dashboard

## Project Overview

This project analyzes hospital patient data using Excel to identify trends in:

* Medical conditions
* Medication usage
* Admission types
* Length of stay

## Tools Used

Microsoft Excel (Data Cleaning, Pivot Tables, Dashboard)

## Key Features

* Interactive dashboard with slicers
* KPI cards (Total Patients, Revenue, Avg LOS, Emergency Cases)
* Pivot table analysis for:

  * Medical conditions
  * Medication usage
  * Admission trends

## Files Included

* `Healthcare_cleaned_dataset.csv` → Contains full dashboard and analysis

## Insights

* Identified most common medical conditions
* Analyzed medication distribution across patients
* Evaluated hospital admission patterns
* Measured average length of stay

## Outcome

This project demonstrates practical data analysis skills using Excel, including data cleaning, transformation, visualization, and dashboard creation.
